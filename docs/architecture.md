# Реальная архитектура прототипа

Состояние зафиксировано 5 ноября 2026 года по версии `gh-pages`:
`df83ea52db23d2ecd52d6c830c70c73ccfc60753`.

## Состав

Статическое приложение без обнаруженных фреймворков и внешних JavaScript-библиотек.
Разметка, CSS, JavaScript, изображения и шрифты DejaVu объединены в `index.html`
(2 591 230 байт, около 1071 строки). Лицензия шрифтов сохранена также в
`LICENSE-DejaVu.txt`. Файл `.nojekyll` отключает обработку Jekyll.

Нет `package.json`, отдельной сборки, серверного приложения, API, БД и автоматических тестов.
Не нужно выполнять `npm install` для текущей версии.

## Представления и маршруты

Ручной маршрутизатор читает `location.hash`, обрабатывает `hashchange`,
переключает `.site-view` через `hidden`, меняет заголовок документа и фокус.

| Маршрут | Представление |
| --- | --- |
| `#/` | Главная |
| `#/directions` | Главная с переходом к направлениям |
| `#/course/oge` | ОГЭ |
| `#/course/base` | ЕГЭ база |
| `#/course/profile` | ЕГЭ профиль |
| `#/lesson/powers` | Теория степеней с целым показателем |
| `#/lesson/powers?section=…` | Раздел теории |
| `#/about` | О преподавателе |
| `#/account` | Демовход либо заглушка кабинета |
| Неизвестный путь | Экран «Страница не найдена» |

Разделы теории: `meaning`, `zero`, `negative`, `properties`, `signs`, `example`.
Сохранены специальные переходы `#trial-lesson` и `#main`.
Все три направления предлагают один общий пробный урок.

## Данные и вход

Учебный контент находится в HTML, описания направлений — в объекте `courses`.
Сетевых вызовов API и использования cookies, localStorage, sessionStorage или IndexedDB
в коде не обнаружено.

Любой непустой текст в двух полях открывает демонстрационный сценарий:
ползунок, затем четыре числа по возрастанию. Успех задаёт переменную
`demoSignedIn` в памяти страницы. Перезагрузка сбрасывает её.
Поля очищаются при уходе с формы и после успешного демовхода.
Есть показ пароля, обновление чисел и выход из демокабинета.

Это не авторизация и не защита от ботов. Приватных материалов и прав доступа нет.

## Ограничения

Кабинет — заглушка; видео, интерактивные задания, проверка ответов, прогресс,
остальные уроки и административный интерфейс не реализованы.
Маркетинговые упоминания видео и практики не подтверждают наличие этих функций.

Монолитный HTML, встроенные ресурсы и повторные определения CSS усложняют сопровождение.
Hash-маршруты используют единый документ и общие исходные метаданные.
Адаптивные стили, ARIA и клавиатурные обработчики присутствуют, но их наличие
не заменяет браузерную проверку.
