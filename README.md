# Tavaspar Education — тестовая версия

Эта ветка содержит готовую статическую версию сайта для GitHub Pages.

## Включить размещение

В настройках репозитория откройте **Settings → Pages**:

1. В разделе **Build and deployment** выберите **Deploy from a branch**.
2. Выберите ветку **gh-pages**, папку **/ (root)** и нажмите **Save**.
3. После завершения публикации GitHub покажет адрес сайта и кнопку **Visit site**.

## Что включено

Главная, направления, теория по степеням и демонстрационный вход в личный кабинет. Для входа подходит любой непустой текст в двух полях; после ползунка нужно нажать четыре числа по возрастанию. Данные не отправляются и не сохраняются. Настоящая авторизация и защита от ботов не подключены.

Разметка находится в `index.html`, стили — в `assets/css/site.css`, JavaScript — в `assets/js/site.js`. Шрифты встроены в CSS, изображения — в HTML. Для размещения нужно сохранять каталог `assets` рядом с `index.html`. Ветка не содержит исходных переписок, ответов преподавателя или личных файлов. Лицензия шрифтов включена в HTML и файл `LICENSE-DejaVu.txt`.

Разработка ведётся в `develop`; обновление `gh-pages` и публикация — только с разрешения владельца. Инструкции по локальной проверке и smoke-тестам: [docs/testing.md](docs/testing.md).
